# Factory game

A small browser factory game. Hauler bots move everything by default and wear
roads into the ground; you build conveyors, arms and ropeways where the traffic
shows you they are needed.

Status: milestones M0–M2 built (terrain, camera, buildings, haulers). See
[`docs/roadmap.md`](docs/roadmap.md) and `CLAUDE.md` for commands. Start with [`docs/design.md`](docs/design.md),
then [`docs/roadmap.md`](docs/roadmap.md).
